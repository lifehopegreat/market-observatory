# 观澜 · 宏观与产业研究工作台

以经济学为主线，用历史数据、政策、财报、市场预期、业内信息、民生与公众意愿交叉验证市场趋势。独立的本地应用，不是静态页面，不含虚构的经济指标、新闻、民意比例或预测胜率。

## 使用

公开发行包仅包含源码、依赖清单、文档与测试，不附带任何本地数据、研究记录或密钥。首次启动会建立空白工作台；从页面同步公开数据或配置你自己的服务。

地址：<http://127.0.0.1:8765>。Windows 在本目录运行 `启动观澜.ps1`，会创建独立 Python 环境、按 lockfile 安装前端依赖、构建并在回环地址后台启动应用，随后打开浏览器。默认不暴露到局域网或公网。

环境：Python 3.12+、Node.js 22+、npm。首次安装需要网络；已有历史快照可离线查看、导入、绘图和生成本地简报。

手动开发：在项目目录运行：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.lock
npm ci
npm run build
.\.venv\Scripts\python.exe -m uvicorn backend.app:app --host 127.0.0.1 --port 8765 --no-access-log
```

前端热更新另开终端运行 `npm run dev`，访问 Vite 显示的本地地址；`/api` 代理到 8765。API 文档位于 <http://127.0.0.1:8765/docs>；写接口需要 `X-Observatory-Request: 1` 和 JSON，交互文档默认不代填此安全标记。

## 建议工作顺序

1. **宏观总览**：刷新世行数据，建立 1990 年以来的历史基线；可切换中国、美国、全球。
2. **行业研究**：按已存在行业标签下钻，观察增加值占比、消费与外贸等。细分行业可用 CSV 扩展，不能用宏观占比代替产业景气。
3. **图表实验室**：选指标、时间范围、同口径比较、移动平均、线性拟合、框选区间、十字线、全屏、数据表、CSV、PNG。同比与基期100仅对适用的水平值开放。
4. **证据库**：以七维分类搜索或录入材料，记录原文、日期、来源类别、事实/观点/假设、传导机制、反证、样本与政策阶段。默认待核验。
5. **研究室**：先生成本地确定性简报，或使用已配置模型生成带引用、情景、反证与缺口的研判；保存完整数据和证据快照。支持 Markdown 和浏览器打印 PDF。
6. **数据与 API**：保存服务端凭据，执行真实采集，查看成功/失败日志。连接失败不覆盖上次成功数据。

## 已实现的数据连接

### AI增量更新与每日计划

在“七维证据库 → AI 更新资料”选择地区、主题和近30/90/180/365天范围，点击“立即 AI 更新”。任务在后端执行，离开页面或关闭浏览器不影响本轮；重新进入可查看进度和最近8轮记录。

- 每轮六类各一次检索，最多读取两份正文/类、最多六次模型整理（最多12条材料）。复用已配置的DeepSeek官方Search/模型Key，或Tavily检索+已配置的Chat Completions模型。任务不把整库数据或凭据发送到模型，仅发送主题与本轮公开来源片段。会产生检索/模型费用。
- 检索须返回可用正文，只有搜索摘要的结果跳过；财报可补读受支持交易所披露域名的PDF，每轮最多两份、每份6MB/前6页，扫描版不做OCR，不向目标站传模型凭据。互动问答不当财报。AI引用来源编号与连续正文依据须匹配。发布日期缺乏正文支持则留空，已确认过旧/未来材料跳过；不保证覆盖所有新发布信息。所有AI材料均待人工核验。
- URL去跟踪参数、正文摘要哈希去重，同一地区同一URL同一正文不重复入库；正文变化另存新版本、记录上一版本编号，旧人工材料与研究快照不覆盖。对不同URL的高度重合文本做疑似转载过滤，可能有误判，日志中可查看并人工补录；最多比较最近200个来源片段。同URL修订不被近似匹配过滤。内容截取前12000字符，网页噪声变化也可能产生版本，不代表经济事实变化。
- 可同时刷新WDI以及当前地区已经接入的FRED/Tushare序列；数值来自provider，不交给AI生成。手动CSV不自动改写，未配置的额外服务不凭空接入；失败保留上次成功数据，各步骤单独显示错误。
- “开启每日更新”保存当前参数，每24小时检查一次，默认关闭。**仅后端运行时执行**；关闭计划不取消本轮。错过多天只补跑一次；中途关服务标记任务中断，不自动重放付费调用。重启后计划仍保存。
- 本地启动器使用单个Uvicorn worker，不支持多worker调度部署。后台任务写入前有数据库互斥，手动触发至少间隔60秒。计划未启动会显示错误，不以失败冒充更新成功。
- 旧报告和上次手工导出的Markdown/JSON索引不会自动重写。本轮日志与来源依据在应用内查看；来源快照为检索服务返回的有限片段，并非全站归档。

接口：`GET/POST /api/updates`（POST返回202任务）、`GET /api/updates/{id}`、`PUT /api/updates/plan`；写入需同源JSON和本地标记，调用需`consent:true`。`GET /api/evidence/{id}/source`可查自动入库材料的来源片段、哈希与版本关系，手工材料无此快照则404。密钥仍由原设置接口管理，任务接口不接收/回显密钥。

| 入口 | 内容 | 凭据 | 边界 |
|---|---|---|---|
| World Bank WDI | GDP、CPI、失业率、居民消费实际增速、制造业/服务业/工业/农业占比、出口、人均GNI、人口、资本形成 | 无 | 年频长序列，不是实时中国宏观；不同指标最新期不同 |
| FRED | 按序列 ID 拉取元数据与观察值 | FRED API Key | 当前修订版；保留此后采集快照，不声称已重建全部 ALFRED vintage |
| Tushare Pro | 单只股票近三年日线 OHLC/成交量 | Token 与日线权限 | 未复权，除权可能跳空；不是产业基本面 |
| DeepSeek Search | 原始材料搜索，政策/统计/财报按地区限定来源域名 | 复用官方 DeepSeek 模型 Key | 独立真实 Search API，不让语言模型编造搜索结果；结果待核验 |
| Tavily Search | 政策、财报、行业、民生与公众材料检索 | 搜索 Key | 配置后优先使用；不自动把摘要变事实 |
| CSV | 官方月季数据、行业财务、调查构成、OHLC | 无 | 手动提供真实材料、单位和口径，用户导入不自动认证 |
| OpenAI-compatible 模型 | 经济学框架下的证据综合 | 模型 ID、Base URL、Key | Chat Completions + JSON；真实引用编号校验不等于内容/因果已验证 |

DeepSeek 官方文档：<https://api-docs.deepseek.com/>、<https://api-docs.deepseek.com/guides/search/>。使用 `/models` 实际返回的模型 ID，而不是假设旧模型名仍有效。设置页也支持其他兼容服务。

### 密钥与隐私

- Windows 使用 DPAPI 当前用户加密，保存于忽略版本控制的本地 SQLite。接口只返回“是否已配置”，不返回密钥。迁移数据库到另一个 Windows 用户后需重新配置。
- 也支持 `OBSERVATORY_MODEL_KEY`、`FRED_API_KEY`、`TAVILY_API_KEY`、`TUSHARE_TOKEN` 环境变量；环境变量优先。本地清除操作不删除环境变量。
- 非 Windows 不落盘保存密钥，只支持上述环境变量。
- **研究材料不是加密存储**：数据、摘录、笔记与报告保存在本地 SQLite，请使用可信电脑和磁盘访问控制。不要直接上传整个 `data` 目录或将其加入备份包，其中有加密凭据。
- 模型研判提交前需同意将所选范围的材料发送到已配置服务商；搜索词也会发送给搜索服务商。模型和搜索可能产生费用。
- 密钥若曾发送到聊天或其他可共享记录，应在服务商控制台轮换，再在设置中更新。
- 默认网络直连；可启用系统代理。禁止跨源写入、非 JSON 写入及恶意 Host；服务只监听回环地址。这不是面向公网的多租户服务。

## CSV 契约

共同要求：UTF-8（可有 BOM），单次不超过 2 MB / 20,000 行；日期按频率为 `YYYY`、`YYYY-MM`、`YYYY-Qn` 或 `YYYY-MM-DD`。数字不可用 NaN/Infinity，缺失留空。重复日期或日期/分类键直接拒绝，不自动覆盖。整批验证通过才写入。

| 结构 | 必要列 | 图表与校验 |
|---|---|---|
| 时间序列 | `date,value` | 折线、面积、柱状；年/月/季度缺期补 null 断线，不补造数值 |
| 日 OHLC | `date,open,high,low,close`，可有 `volume` | K线、收盘折线、柱状；低≤开/收≤高；价格正数、成交量非负 |
| 同一时点构成 | `date,category,value` | 饼图、柱状；同一日期、非负、总和正数，需明确确认分类互斥；百分比以本表合计为分母 |

导出 CSV 保留来源、单位和采集时间，文本公式前缀转义。不存在“宏观月度数据转 K线”或“跨年份增速拼饼图”。柱轴包含零基线；拟合只是样本内统计，不是预测；同比匹配上年同期而非上一条非空记录。

## 数据和工程结构

```text
backend/             FastAPI、SQLite、输入验证、provider 与研究引用校验
src/                 React、七个研究视图、ECharts、日夜主题、图表数学
tests/               后端单元/API 测试与隔离的浏览器验收
scripts/live_check.py 真实数据/模型连通检查（--ai 会发送材料并产生调用费用）
PLAN.md              研究来源、实施顺序、两轮审查与修正记录
DESIGN.md            Swiss、香槟金、银白/石墨双主题与证据链设计
data/                本地数据库、凭据、快照、研究与运行日志（全部 gitignored）
```

研究方法与资料参考见应用“方法与使用边界”、`PLAN.md`。未采用未经校准的综合经济评分或情景概率。

```powershell
python -m unittest discover -s tests -p "test_*.py" -v
npm test
npm run build
npm run test:e2e
python scripts/live_check.py --refresh
# 以下会向已配置服务商发送研究数据并调用付费模型

```

浏览器测试在独立 8877 端口与独立 `data/e2e-*` 数据库运行，不读取主库的密钥。合成数值仅存在于明确命名的隔离自动化测试夹具，不出现在真实应用数据中。优先复用本机已有 Chromium；其他环境可用 `npx playwright install chromium` 或设置 `PLAYWRIGHT_CHROMIUM_EXECUTABLE`。

## 当前明确边界

没有自动接入所有部委/行业协会/企业的私有数据，没有全国代表性的原生民调数据库，也没有把年度数据伪装为月度实时数据。中国高频宏观、细分行业财报和调查目前通过官方材料检索与 CSV 接入；FRED、Tushare 的真实认证采集需用户相应凭据。这些缺口在研究报告中显式出现，而不由模型补齐。

本版本不含交易、多用户登录、云端同步、常驻系统级爬虫与自动推送；支持项目运行期间的每日AI资料更新。它实现本地研究闭环，不代表预测准确性已被证明。
